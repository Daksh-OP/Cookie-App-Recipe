# 🍪 Cookie Recipe App

A simple, clean, and responsive recipe app that lets you browse cookie recipes by time, category, or search.  
Includes Dark Mode, settings menu, and smooth transitions.

## 🚀 Features

- 🎨 Clean UI with smooth animations  
- 🌓 Dark Mode (saved in localStorage)  
- 📱 Fully responsive layout for phone, tablet, desktop  
- 🔍 Instant search feature  
- ⏱️ Filter recipes by preparation time  
- 📂 Filter recipes by category  
- ⚙️ Settings menu (language, dark mode, etc.)  
- 🖼️ Supports your own images
